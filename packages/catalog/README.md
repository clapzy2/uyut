# @uyut/catalog

Разбор товарных фидов, хранение каталога и поиск похожих товаров по вектору картинки.

## Источники

- **CSV-дамп** — ручная выгрузка для разработки, `parseCsvDump`. Импорт: `bun run catalog:import путь/к/файлу.csv`, после импорта сразу считаются векторы, если в `.env` есть `VOYAGE_API_KEY`.
- **YML** — формат Яндекс.Маркета, в нём отдают фиды Admitad, `parseYml`. Ссылки фидов задаются переменными `ADMITAD_FEED_<ИСТОЧНИК>_URL`, например `ADMITAD_FEED_OZON_URL`; источник берётся из имени переменной и должен быть из списка `catalogSources`.

Категория товара восстанавливается по дереву категорий фида и названию словарём `categoryFromText`. Товары вне восьми категорий каталога пропускаются, причина попадает в `skipped`.

## Формат CSV

Одна строка на товар, разделитель запятая или точка с запятой, кодировка UTF-8. Первые шесть колонок обязательные.

| Колонка | Что писать |
|---|---|
| `external_id` | номер товара в магазине, из адреса карточки |
| `category` | `sofa`, `chair`, `table`, `storage`, `lamp`, `rug`, `bed`, `decor`; при другом значении категория угадывается по названию |
| `title` | название как в магазине |
| `price_rub` | цена в рублях |
| `url` | адрес карточки товара |
| `image_url` | прямая ссылка на главное фото |
| `subcategory`, `brand`, `description` | по возможности |
| `old_price_rub` | цена до скидки |
| `color`, `material` | из характеристик |
| `width_cm`, `depth_cm`, `height_cm` | габариты числами |
| `image_url_2`, `image_url_3` | дополнительные фото |
| `in_stock` | `нет`, если товара нет в наличии; по умолчанию есть |

## Обновление и поиск

`upsertFeedItems` пишет пачками по 200 с конфликтом по паре источник плюс внешний id. Хеш названия, описания и первой картинки хранится рядом: если он изменился, задача `embed-catalog` пересчитает векторы. `markMissingOutOfStock` прячет товары, которых в свежем фиде не оказалось.

`findSimilar` ищет по косинусному расстоянию `<=>` в категории и ценовом окне; ivfflat-индекс включается на больших объёмах, на сотнях записей идёт полный скан.

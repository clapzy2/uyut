# ADR-004. Каталог и подбор товаров к концепту

Статус: принято. Дата: 2026-09-06.

## Контекст

На готовом рендере нужно найти предметы мебели и к каждому показать пять реальных товаров из магазинов: с фото, ценой и ссылкой. Каталог приходит из партнёрских фидов и обновляется ежедневно. Подбор одного концепта должен укладываться в пятнадцать секунд.

Спека называет SAM 2 для сегментации. На живой пробе выяснилось, что SAM 2 не знает названий предметов: он режет маску по указанной точке, а какой это предмет, сказать не может. Публичный поиск Wildberries как источник цен с машины разработки не отвечает вовсе.

## Решение

**Детектор — Florence-2 в режиме phrase grounding (`fal-ai/florence-2-large/caption-to-phrase-grounding`).** В подписи перечислены фразы категорий каталога, свои для каждого типа комнаты: для гостиной «a sofa, an armchair, a coffee table, a rug…», для спальни «a bed, a wardrobe…». Модель возвращает рамку на каждую найденную фразу, так что подпись сразу равна категории и словарь не нужен. Обычный object detection той же модели пропускал ковёр и светильники, а открытый словарь через запятую возвращал одну рамку на всю картинку. Рамки хранятся долями от размера картинки, чтобы рисовать их поверх рендера любого размера. Отбираются шесть самых крупных: рамки на всю картинку, крошечные и дубли одной категории с пересечением больше половины отбрасываются.

**Маски — SAM 2 по рамке детектора.** Точки внутри рамки для тонких предметов вроде торшера попадали в стену позади, а рамка удерживает маску на самом предмете. Маска нужна подсветке при наведении и перекраске в следующей фазе; сбой маски не ломает подбор, предмет остаётся с рамкой.

**Векторы — Voyage Multimodal 3.** Вырезка предмета с небольшим отступом и картинка товара из фида считаются одной моделью, поэтому сравнимы напрямую. Для товара дополнительно считается текстовый вектор по названию и описанию, он пригодится текстовому поиску. Картинки товаров уменьшаются до 512 px перед отправкой: Voyage считает токены по пикселям, десять картинок обходятся в доли цента.

**Поиск — pgvector по косинусному расстоянию** в категории предмета и ценовом окне. Окно считается от доли бюджета проекта на категорию: диван четверть, кровать пятая часть, хранение двенадцать процентов и так далее, от трети доли до полутора. Если в окне меньше трёх товаров, недостающие добираются ближайшими без потолка цены и помечаются «выше бюджета»: человеку полезнее увидеть цену того, что понравилось, чем пустую панель. Порог уверенности 0.35 по косинусу: ниже него панель называется «похожие по стилю». Значение 0.5 из спеки отрезало бы половину верных совпадений, у Voyage хорошие пары дают 0.45–0.60.

**Пять товаров считаются на лету при открытии концепта**, в базе хранится только лучший матч и его уверенность. Каталог растёт каждую ночь, и панель улучшается без пересчёта старых концептов.

**Каталог обновляется задачей Trigger.dev по cron в 03:00 UTC.** Фиды Admitad в формате YML задаются переменными `ADMITAD_FEED_<ИСТОЧНИК>_URL`, upsert идёт по паре источник плюс внешний id, пропавшие из фида товары прячутся из наличия. Векторы считаются отдельной задачей только для новых и изменённых записей: рядом с записью хранится хеш названия, описания и первой картинки. Для разработки тот же путь проходит ручной CSV-дамп командой `catalog:import`.

**Подбор запускается автоматически** из задачи генерации на каждый удачный рендер, чтобы страница концепта открывалась уже с номерами на предметах.

## Последствия

- Один концепт: детектор около 5 с, маски параллельно около 4 с, векторы около 2 с, поиск мгновенный; итого 10–12 с и около четырёх центов.
- В базе появились `catalog_items` и `concept_objects` с ivfflat-индексами; у концепта поля `objects_status` и `objects_error`.
- Пакет `@uyut/catalog` не зависит от приложения и переиспользуется задачами и страницами.
- Категорий восемь: диван, кресло, стол, хранение, светильник, ковёр, кровать, декор. Кухонные фасады и сантехника не в этой фазе.
- Без ключа Voyage предметы находятся, но подбор помечается пропущенным; без фидов ночная задача только досчитывает векторы дампа.

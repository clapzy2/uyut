# Домица - действующий план

Обновлено 22 ноября 2026. База аудита: main `7a4d48a`.

Цель ограниченного пилота: фото комнаты или план -> визуальный интерьер ->
подходящие товары -> предварительная расстановка -> понятный PDF.
Точное размещение требует отдельно подтверждённой геометрии; оно не блокирует
визуальный концепт. Точный перенос исходного предмета пока не принят.

## Единственная таблица готовности

[READINESS.md](READINESS.md) содержит фиксированные критерии, доказательства,
проценты и журнал изменений. Процент меняется только после закрытия критерия.
Количество тестов, коммитов и исследованных планов не повышает готовность само по себе.
Исторические экспертные 75% не сравниваются с новой долей закрытых критериев.

## Очередь пакетов

1. **Целостность и аудит (сейчас).** Согласовать спецификацию, план и статус;
   проверить сборку, типы, линтер, текущий CI/health; собрать независимые замечания.
2. **Бесплатная сквозная приёмка.** На сохранённом проекте проверить товары,
   размеры, сохранение позиции, 2D/3D и PDF одной версии. При отказе фиксировать
   место и причину, исправлять только воспроизведённые ошибки одним пакетом.
3. **Качество модели.** Отдельный небольшой корпус правок, запретов и переноса
   предмета. Сначала сохранённые результаты и локальные проверки. Новый платный
   вызов только если он отвечает конкретному вопросу, с заранее указанным пределом
   расходов. Нынешние $4-6 не считать измеренным остатком баланса.
4. **Эксплуатация и пилот.** Проверить актуальность каталога, резервное
   восстановление, полный учёт расходов и независимого пользователя/телефон.
   Массовый запуск не объявлять до приёмки этих пунктов.

После каждого пакета: результат -> проверки -> закрытые ID критериев -> изменение
процента соответствующего блока -> оставшиеся ограничения. Один связный коммит;
выкладка нужна для изменений сервиса, не для каждой записи аудита.

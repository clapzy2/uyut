# Очистка локальной Домицы — 27 сентября 2026

## Граница

Владелец разрешил удалять только ненужное в Room_project и относящееся к Домица в Docker.
Другие проекты, пользовательские файлы, исходники, секреты, резервные копии и тома с данными
не входят в очистку. Глобальные Docker prune, factory reset и сжатие общего VHD не выполнялись.

## Проверено и выполнено

- Основной объём — `.turbo`: 65,155 GiB, 591 файл. Большие архивы предыдущих сборок
  включали локальные артефакты Next.js; `.next` занимает отдельно около 4,75 GiB.
- Кэширование `build` в Turbo отключено, `.next/dev` также исключён из списка выходных файлов.
  Test/typecheck по-прежнему кэшируются. Dry-run подтвердил отключённый кэш у всех 7 build-задач.
- Удалены только два остановленных compose-контейнера проекта `uyut`: `uyut-s3-1` и
  `uyut-postgres-1`. Принудительная остановка и удаление томов не применялись.
- Удалена одна адресно проверенная запись buildx-кэша `koharv8ql1uvgkrdx7qzlxh9s`,
  описанная как сборка `@uyut/web`: 576,3 MB. Она была неиспользуемой и не разделялась
  с другими образами. Остальные записи не затронуты.
- Сохранены `uyut_minio-data`, `uyut_postgres-data`, `uyut_redis-data`, `uyut_seaweed-data`.
  Зависимости и текущие артефакты проверки не удалены.

## Осталось

Удаление `.turbo` командой Remove-Item заблокировано политикой исполнения. Папка остаётся;
65 GiB не считаются освобождёнными. Альтернативные способы обхода блокировки не применялись.

Ручной шаг для владельца: открыть `C:\Users\Lenovo\Desktop\Room_project`, выбрать **только
`.turbo`**, нажать Shift+Delete. Это восстанавливаемый кэш сборок, не исходники и не данные.
После удаления folder size/free disk проверяются заново. Next.js и глобальный Docker-кэш
не предлагаются к массовой очистке: сначала нужно отдельно проверить зависимые процессы.

Docker сообщает освобождение внутри своего диска; физический размер VHD на Windows может
не уменьшиться сразу. Свободное место диска C меняется и из-за других приложений, поэтому
разницу показателей до/после нельзя приписывать только этой очистке.

# Архитектурный якорь вариантов

## Проверенный результат

Для комнат без фотографии первый рендер пакета теперь становится визуальной основой остальных.
Производные варианты получают тот же кадр через edit endpoint и явное требование сохранить
положение камеры, стены, пропорции, потолок, окна, двери и другие проёмы.

Реальный контроль выполнен на гостиной 4×5 м с двумя отдельными окнами и простенком:

- создан один производный вариант, без записи в БД и без загрузки в пользовательский проект;
- сохранены ракурс, прямоугольная форма, два окна, простенок и дверь слева;
- диван, кресло и книжный шкаф переставлены;
- автопроверка вернула checked без замечаний;
- один новый оплачиваемый рендер, автоматических повторов не было.

Локальные исходник, результат и сырой ответ находятся в исключённой из Git папке
`output/quality-bench`. Подписанных ссылок, ключей и пользовательских данных в репозитории нет.

## Отказоустойчивость и стоимость

- Количество картинок в пакете не изменилось: первый рендер плюс N−1 edit-рендеров.
- Первый запрос не повторяется при ошибке; остальные N−1 возвращаются к независимому режиму.
- Ошибка одного производного edit-запроса не скрывается и не запускает второй платный запрос.
- Варианты с фотографией комнаты продолжают использовать исходную фотографию напрямую.
- Обработка результатов начинается по мере их готовности, без ожидания всего пакета.

## QA Release Gate

BLOCKERS для обещания точного проекта остаются: якорь согласует варианты между собой, но первый
кадр всё ещё является интерпретацией текстового плана и не подтверждает сантиметровую геометрию.

IMPORTANT: один реальный контроль не является статистикой. Следует накопить размеченные пары
для кухонь, узких комнат и сложных планов, измеряя сохранение проёмов и полезность вариантов.

POLISH: производные варианты могут быть визуально ближе друг к другу. Это осознанный обмен
части разнообразия на узнаваемость одной комнаты.

Рекомендация: выпускать для новых генераций как улучшение согласованности. Старые концепты не
перезаписывать. Откат — возврат к независимым запросам; миграций данных нет.

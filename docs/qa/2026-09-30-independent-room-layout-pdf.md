# Независимый обмер → предварительная расстановка → PDF

`spb_pobedy_5_design_project.pdf`, SHA-256
`180ac586af50432ecbd9c166251a8de7d008a6f1f98f72b946d9ce2cfe7ee4e9`.
Проектные листы не использовались.

Повторный запуск контрольной разметки спальни №05 обнаружил дефект QA: отдельная
комната успешно переносилась из PDF, но проверочный скрипт требовал поле
`pdfCalibration`, которое создаётся только в режиме общего масштаба квартиры.
Теперь для проверки отчёта масштаб повторно берётся из уже проверенной нативной
горизонтальной цепочки. Производственный алгоритм переноса размеров не менялся.

Итог по комнате №05: нативные подписи `1194 + 1900 + 600 = 3694 мм` и `4477 мм`
приняты; 0 ошибок геометрии. Нет внешнего контура квартиры, поэтому серверная
проверка подтверждения остаётся с ошибкой `manual-missing-outer-walls`.
Проверка комнат №03 и №05 вместе тоже проходит перенос мерок, но сохраняет
`manual-disconnected-walls` и `manual-missing-outer-walls`.

Локальный сценарий QA печатает PDF тем же HTML-шаблоном и Chromium-функцией,
что используются для экспорта. В него попадает одна сверенная спальня и
**тестовая**, а не каталожная кровать 140 × 200 см. Сервис намеренно выдаёт
`needs-data`: это прямоугольное превью по меркам, не принятый контур, без
подтверждённых двери, окна, маршрута и состояния отделки. Смета не проверяется;
в тестовых данных она нулевая. Сформирован 6-страничный PDF, визуально проверены
страницы с пояснением и 2D-схемой. Расход AI — 0.

Повторить из `apps/web`:

```powershell
bun run scripts/qa-independent-metric-room.ts C:/Users/Lenovo/Downloads/spb_pobedy_5_design_project.pdf ../../docs/qa/fixtures/spb-pobedy-5-existing-room-05.json ../../output/playwright/spb-room05-source.png ../../output/pdf/spb-room05-source-layout.pdf
```

Этот тест проверяет передачу подтверждённых *мерок одной комнаты* в печатный
путь и защиту от ложного принятия. Он не закрывает критерий целой квартиры
из [решения по 2D](2026-09-29-2d-closure-decision.md): физическая модель стен,
внешний контур, все комнаты, проёмы и полноценная расстановка остаются
неподтверждёнными.

# Подбор мебели: строгий вид и порог качества

## Что исправлено

- Название товара теперь имеет приоритет над описанием: «Стул …, мягкое кресло» остаётся
  стулом, а «Ваза для цветов» — вазой.
- Когда детектор знает вид предмета, поиск больше не добирает товары другого вида из общей
  категории: стул не заменяется креслом, картина зеркалом, растение вазой.
- Порог сходства применяется к каждому предложению отдельно. Сильный первый результат больше
  не протаскивает слабые позиции №2–5.
- Если товары в бюджете не прошли порог, поиск может показать подходящий товар того же вида
  вне бюджета. Он по-прежнему помечается как превышающий бюджет.
- Фоновая обработка не сохраняет слабый товар как найденное совпадение.

товаров. Без размеров сервис вправе говорить только о визуальном совпадении, не о физической
совместимости.

IMPORTANT: порог 0,45 основан на наблюдавшихся ошибочных и реальных совпадениях, а не на большой
размеченной выборке. Следующий контроль — собрать precision@5 отдельно по типам комнат и товаров.

# Замена фото комнаты после генерации, 27.10.2026

Проверен локальный QA-проект на мобильном Edge шириной 360 px. В комнате были
сохранены фото и один тестовый концепт. Заменили фото другим JPG без вызова
модели. После загрузки и повторного открытия прежний концепт сохранился, а в
списке и на его странице появилась пометка «Не по текущему фото». Общий запуск
по квартире снова включает эту комнату; кнопку платной генерации не нажимали.
Для честной проверки картинки тестовый концепт хранит отдельный файл рендера,
как и реальные варианты. После замены фото изображение загрузилось (1800 px).
Прежний вариант отмечен понравившимся в локальном QA, после чего предупреждение
появилось и в разделе «Состав следующего PDF». Сам экспорт через очередь не
запускался; текст в собранном PDF проверен профильным тестом.

| Случай | Результат |
| --- | --- |
| Фото меняют во время генерации | Замена отклоняется атомарно; прежний ключ и ревизия не меняются, новый загруженный объект удаляется. Проверено через действие и локальную БД. |
| Две одновременные замены | Одна проходит, вторая отклоняется; ревизия растёт один раз. Проверено на локальной БД. |
| Старый концепт после замены | Сохраняется и получает пометку в комнате, карточке, предпросмотре PDF и документе. |
| Новый концепт по текущему фото | Запись с текущей ревизией учитывается общим запуском. Проверено на локальной БД; платную генерацию не запускали. |
| Правка прежнего концепта | Код генерации наследует исходную ревизию, поэтому новое время создания не скрывает старый источник. Сам платный прогон правки не выполнялся. |

Ревизия 0 сохраняет прежнее поведение для существующих проектов. Старая запись
без ревизии помечается только после первой замены фото. Концепты и выбранные
товары не удаляются. Содержимое концептов на точность соответствия новому фото
не проверялось; платная генерация, живой сайт и реальная замена фото владельцем
этим локальным прогоном не выполнялись.

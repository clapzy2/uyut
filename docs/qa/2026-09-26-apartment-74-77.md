## Выполненная ограниченная пачка

1. В форме можно выбрать страницу PDF. Сервер проверяет диапазон, растеризует один лист и
   выполняет один запрос; больше нет скрытых запросов на первые три страницы и до 12 сторон.
2. Парсер сохраняет миллиметры (2964 → 296,4 см), сотые площади и отдельные потолки.
   Null не достраивается из площади/aspect. Кнопки подгонки сторон по площади удалены.
3. Номера из экспликации различают спальни №4 и №6 независимо от порядка ответа. Состояние
   листа, номер страницы и количество страниц сохраняются. Проектный лист имеет предупреждение.
4. PDF-текст извлекается бесплатно с координатами и поворотом подписей; растровые сканы могут
   не иметь такого слоя. Позиции текста — нормализованные координаты страницы, не обмеры стен.
5. Валидация и сохранение передают индивидуальные потолки в комнаты, не создавая общий потолок
   из диапазона. Чтение не создаёт подтверждение фактического замера. Предупреждение о расхождении
   площади не объявляет автоматически ошибку стороны: причиной может быть ниша/скос.

1. Геометрия не сохраняла номер помещения: два контура «Спальня» не связывались с уже

2. Проверка только площади пропускала переставленные оси. Габариты контура сверяются по

## Бесплатная пачка 27 сентября: доказательство числа и проходы

Для новых вызовов читателя добавлен обязательный контракт `measurementEvidence`: назначение
подписи, room/apartment, напечатанный номер либо уникальное название помещения, полнота
цепочки и её отрезки. Число принимается только при совпадении суммы с заявленным размером;
потолок содержит один отрезок, не сумму диапазона. Код не меняет ошибочную сумму на своё
число молча и не дополняет отсутствующие звенья.

При наличии текстового слоя PDF отрезки должны ссылаться на конкретные индексы его массива.
Проверяются число, единицы, отсутствие повторного/несуществующего индекса и ориентация
размерной подписи. Потолки также проверяются по назначению текста; для общего потолка нужна
явная общая подпись, не локальная выноска спальни. Скан без текстового слоя остаётся зрячим
чтением с проверкой заявленной принадлежности и арифметики, без подтверждения существования
подписей кодом. Конфликт или отсутствующая цепочка оставляет размер неизвестным; строка и
подписанная площадь сохраняются, пояснение попадает в форму сверки. Старые ответы без нового
контракта разбираются в совместимом режиме; это не переводит их в подтверждённые обмеры.

**Граница проверки:** номер комнаты, полноту цепочки и назначение выноски по-прежнему
заявляет модель. Если она выберет чужую горизонтальную линию и одновременно подпишет её
правильным номером комнаты, эта проверка сама по себе ошибку не обнаружит. Концы размерных
линий и стрелки выносок код ещё не распознаёт. Совпадение чисел в PDF не доказывает их
пространственную принадлежность. Новый контракт требует реального теста качества чтения,
который сейчас не запускался: оценка **7/12** прежнего ответа не повысилась.

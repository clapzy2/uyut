# Сверка сохранённых концептов с брифами — 23 сентября 2026

## Метод

Вручную просмотрены семь сохранённых синтетических рендеров и производный вариант гостиной.
Для каждого использован исходный бриф из `jobs/scripts/quality-bench-cases.ts` и сохранённый
ответ проверяющего из `output/quality-bench`. Это сравнение с текстом задания, а не с чертежом:
реальных пар «план квартиры — рендер» в этой выборке нет. Новых изображений и вызовов AI не было.

«Совпадает» ниже означает только, что видимая архитектура не противоречит брифу. Проёмы вне
кадра, точные размеры и форму пола по перспективе не подтверждаем.

| Кадр | Ручная разметка | Автопроверка | Вывод |
| --- | --- | --- | --- |
| Узкая кухня | Одно окно на дальней стене; вход за камерой, его положение не видно. Линейный гарнитур, острова нет. | checked | По видимой части противоречий нет; вход не подтверждён. |
| Кухня для троих | Окно и дверь справа видны. У стола два стула вместо трёх запрошенных мест. | review: requirement_unconfirmed | Замечание по посадочным местам верное; точное положение двери по перспективе не доказать. |
| Узкая гостиная | Комната выглядит вытянутой; окно на дальней стене, вход у камеры. Диван и ТВ видны. | checked | Грубого противоречия нет; ширину 240 см кадр не доказывает. |
| Гостиная с двумя окнами | Два раздельных окна и простенок хорошо видны; вход у левого края. | checked | Число и видимое взаимное положение окон совпадают. |
| Компактная спальня | Одно окно, вход и шкаф видны; сторону окна относительно плана по ракурсу нельзя подтвердить. | unavailable | У проверяющего нет заключения. Размер кровати и проход не измеримы по кадру. |
| Спальня без окон | Видимых окон нет; есть дверь. Выступ у потолка и ниша за шкафом не позволяют уверенно подтвердить строгий прямоугольный контур пола. | checked | Нет доказанного противоречия, но `checked` не означает, что форма комнаты подтверждена. |
| Маленькая кухня хрущёвки | Окно, радиатор, дверь справа и три табурета видны. Появились диван и книжная полка; комната выглядит просторнее брифа. | unavailable | Сохранённый кадр создан до исправления правил семейного брифа; улучшение визуально ещё не перепроверено. |
| Производный вариант гостиной | Оба окна и простенок сохранены относительно исходного кадра; мебель переставлена. | checked | Один положительный пример работы визуального якоря, без оценки статистической надёжности. |

Из восьми основных проверок шесть вернули результат: пять `checked`, одна `review`.
Две вернули `unavailable`. На единственном ясно видимом нарушении конкретного пожелания
проверяющий сработал. Этого недостаточно, чтобы посчитать точность оценки архитектуры.

Дополнительно в локальном архиве есть прежний отрицательный контроль: тому же кадру с двумя
окнами дали условие «окон нет»; проверяющий вернул `opening_conflict`. Это один контрольный
пример, а не оценка частоты ошибок.

## Что следует сделать дальше

1. Собрать несколько пар с настоящими подтверждёнными планами и рендерами, включая кухни,
   непрямоугольные комнаты, балконные блоки и два входа.
2. Размечать отдельно «видно совпадение», «видно противоречие» и «ракурс не позволяет проверить»
   для формы, каждого окна и каждой двери. Не смешивать неуверенность с совпадением.
3. После отдельного решения по AI-бюджету повторно проверить маленькую кухню на обновлённом
   брифе и измерить пропуски/ложные тревоги проверяющего на размеченной выборке.

Автоматическая проверка остаётся рекомендацией. Обещать по её результату точный интерьер
по размерам или гарантированное сохранение всех проёмов нельзя.

# Ручная сверка пары граней PDF

Пользователь разрешил отдельное подтверждение пары с отметкой «сверено человеком».
Размеры, толщины, высоты и уровни пола из такой сверки не вычисляются.

## Поведение

Редактор исходного PDF предлагает точные пары граней одного замкнутого исходного
контура. Обе грани связаны с существующими рёбрами 2D-черновика и сохраняют ссылки
на исходную заливку/контур и независимые штрихи. Короткие угловые остатки, изменённые
стены, неоднозначные снимки комнат и пересечения с текущими проёмами не предлагаются.

Владелец выбирает пару, видит обе грани на PDF и может скрыть подсветку для сравнения.
После отдельной галочки сверки сервер заново извлекает PDF, проверяет владельца,
ревизию, SHA, страницу и выбранный кандидат. Сервер сам сохраняет дату и вид
подтверждения. Клиентские координаты и сведения о проверяющем не принимаются.

Автоматическое сопоставление использует прежние проверки видимости. Ручная сверка
хранится с `verification.kind = human-source-review`; происхождение показывается
в 2D, рядом с запуском 3D и в PDF. Изменение связанных стен, проёмов или контуров
комнат прекращает действие сверки. Изменение исходной разметки требует повторного
импорта. Устаревшую ручную пару можно повторно сверить по действующему исходнику;
запись заменяется, не дублируется. Автоматические доказательства этим не заменяются.
Владелец также может снять отдельную ручную сверку. Схема возвращается в черновик,
дата её подтверждения очищается; автоматические пары и мерки сохраняются.

## Проверка на реальном Remplanner

Локальный источник: `tmp/pdfs/remplanner-interior-source.pdf`, лист 4,
SHA-256 `d04de01407f66521282deea2eca5bfca84495bec7652a5eaeae836575e2fcfd5`.
Контроль использует настоящую PostgreSQL и серверные действия. Сессия, выдача
исходника из хранилища и аудит подменены тестовыми адаптерами; production не менялся.

| Шаг | Результат |
| --- | --- |
| Автоматические пары | Прежние 8 пар, проверки видимости сохранены |
| Предложение ручной пары комнаты 5 и наружного контура | Найдено по исходным штрихам; неопределённость видимости показана |
| Явная ручная сверка | Сохранена 1 пара, дата поставлена сервером |
| Повторное открытие | Совпали геометрия, обе исходные ссылки и отметка |
| 2D | Ручная пара действительна, видна в числе сверенных человеком связей |
| Повторное предложение уже принятой пары | Не предлагается второй раз |
| Снятие сверки и повторное открытие | Ручная пара удалена; прежние 8 автоматических пар и все мерки сохранены |
| Подтверждение всей квартиры | Отказ: остаются 34 отрезка вне общей связи |
| 3D реальной квартиры | Не построено: схема не подтверждена; отдельно отсутствует общий отсчёт высот |
| Данные PDF | Присутствует 1 действующая ручная пара, нет выдуманных уровней и объёма |
| Печать | 5 страниц Chromium PDF; все просмотрены, отметка читается на странице проекта |

Контрольный PDF содержит данные тестового проекта без подтверждённых комнатных
планов. Это проверка переноса происхождения сверки в печать, а не готовый PDF
квартиры. Артефакты находятся в игнорируемом `tmp/pdfs/human-wall-review-remplanner-20261024*`.

## Контроли переноса и отказов

На отдельной синтетической фикстуре с заранее заданными и подписанными тестовыми
уровнями ручная отметка переносится в модель объёма и геометрию сцены без изменения
стен, проёмов и вертикального отсчёта. Это контроль потребителя 3D, не обмер Remplanner.

Отрицательные тесты покрывают чужой аккаунт, заменённый PDF, устаревшую ревизию,
поддельный ID, отсутствие явного согласия, клиентскую подмену метаданных, конфликт
записи, смену роли стены, повторный снимок комнаты, правки стены/проёма/комнаты и
устаревшую подсветку после неудачной перезагрузки. Метка PDF исчезает, когда сверка
уже не действует. Недостающие размеры и уровни не добавляются.

## Остаток этапа

Пакет даёт рабочий путь ручной сверки конкретной пары. Полная Remplanner-квартира
пока требует сверки остальных физических связей и уточнения того, какие пунктирные
разделители являются открытыми зонами. Грубая наружная обводка контрольного примера
также требует правки по источнику. На листе нет достаточных отметок чистого пола
для общего вертикального отсчёта. Эти данные одна принятая пара не создаёт.

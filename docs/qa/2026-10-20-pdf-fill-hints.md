# Подсказки заливок PDF: проверка 20.10.2026

Цель этого пакета — показывать исходные заливки непосредственно в редакторе физической обводки, когда строгая проверка не может предложить комнату. Это только слой сравнения с PDF: он не создаёт комнату, не задаёт масштаб и не передаётся в 2D/3D/PDF.

Число заливок — не число распознанных комнат. Измерение «18 из 18» по ближайшим площадям подбирало масштаб по самой таблице площадей и не проверяло уникальность владельца; использовать его как показатель точности нельзя. Для честной оценки нужны новые планы с заранее размеченными эталонными контурами, включая отрицательные примеры и фото/сканы.

Проверка текущего пакета: подсказки запрашиваются только для владельца или участника проекта и только для совпадающей версии PDF; ответ ограничен 50 областями и 100 вершинами на область. В браузере пользователь выбирает одну заливку и видит её пунктиром поверх исходника. Сохранение разметки, перенос в сантиметры и подтверждение геометрии остаются отдельными действиями. Проверка в реальном аккаунте и выкладка ещё не выполнены.

## Подсказки по печатным номерам помещений

Следующий пакет группирует заливки под номерами из экспликации. Номер из самой таблицы и надстрочная «²» исключаются; заливка, содержащая номера нескольких помещений, не предлагается как контур одной комнаты. Совпадение по номеру остаётся диагностикой, а не доказательством физической границы.

| План | Проверка номеров на реальном PDF | Результат подсказок |
| --- | --- | --- |
| DECO, стр. 3 | 5 строк экспликации и 5 номеров на чертеже | После отсева общей заливки: № 1–3 имеют по 2 варианта, № 4–5 по 3. Все остаются неоднозначными. |
| Чигинцева, стр. 3 | 8 строк и 8 номеров | По одному варианту заливки под каждым номером, включая балкон № 8. |
| Муханова, стр. 4 | 5 строк и 5 номеров | По одному варианту под каждым номером, включая лоджию № 3. |

Масштаб из размерных цепей на этих трёх PDF согласуется по осям X/Y после перевода координат листа в PDF-пункты. Интерфейс показывает рассчитанную площадь каждой подсвеченной заливки только при наличии минимум двух согласованных цепей на каждой оси; при конфликте или недостатке цепей площадь скрыта. Площадь экспликации **не** использовалась для выбора заливки. У DECO на самом чертеже указано 17,60 м² для жилой комнаты и 2,46 м² для балкона, тогда как в экспликации — 17,86 и 2,54 м²; это остаётся видимым противоречием источника. Новые подсказки не изменяют сохранённый план и не доходят до 2D/3D/PDF без отдельной физической проверки и подтверждения.

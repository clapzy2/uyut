# Подсказки заливок PDF: проверка 20.10.2026

Цель этого пакета — показывать исходные заливки непосредственно в редакторе физической обводки, когда строгая проверка не может предложить комнату. Это только слой сравнения с PDF: он не создаёт комнату, не задаёт масштаб и не передаётся в 2D/3D/PDF.

Число заливок — не число распознанных комнат. Измерение «18 из 18» по ближайшим площадям подбирало масштаб по самой таблице площадей и не проверяло уникальность владельца; использовать его как показатель точности нельзя. Для честной оценки нужны новые планы с заранее размеченными эталонными контурами, включая отрицательные примеры и фото/сканы.

Проверка текущего пакета: подсказки запрашиваются только для владельца или участника проекта и только для совпадающей версии PDF; ответ ограничен 50 областями и 100 вершинами на область. В браузере пользователь выбирает одну заливку и видит её пунктиром поверх исходника. Сохранение разметки, перенос в сантиметры и подтверждение геометрии остаются отдельными действиями. Проверка в реальном аккаунте и выкладка ещё не выполнены.

# Конкретные запреты при правке интерьера

13.11.2026, пакет поверх c391fa6.

## Исправление

Планировщик больше не исключает конкретные требования сохранения из шага.
Независимо от сокращения моделью renderer получает исходную просьбу дословно
как контекст ограничений. Выполняется только текущий шаг; предыдущие и
последующие действия цепочки повторять запрещено. Старый запуск без исходной
просьбы совместим с прежним форматом.

Парная автосверка раньше прямо запрещала проверять цвет. Теперь сравнивает
цвет и материал конкретного предмета, явно оставленного без изменений.
Сохраняет цитату из последней просьбы, предмет, место и наблюдения до/после;
уверенность должна быть конечным числом 0.8..1. Неподтверждённое изменение
свойства показывается как requirement_unconfirmed, а не как независимо
доказанный brief_conflict. Полнота сравнения остаётся limited.
Эти наблюдения не направляются в проверку пустого места. Доказательства
стен, проёмов, добавления и удаления техники не ослаблены. Дополнительного
запроса для нового пути нет.

Ограничение: если последняя revision существует, старые цитаты из notes
не принимаются. Это консервативно: прежний запрет нельзя использовать против
нового разрешения. Семантика запрета оценивается моделью, код проверяет
происхождение цитаты, формат и уверенность; гарантии всех будущих правок нет.

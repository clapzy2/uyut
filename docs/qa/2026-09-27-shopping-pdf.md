# Выбранный концепт → список → печатные данные — 27 сентября 2026

## Воспроизведено и исправлено

1. `loadSnapshot` запрашивал только понравившиеся концепты, хотя главным должен был стать
   концепт с выбранными товарами. Отдельный тест на настоящем PostgreSQL до исправления
   падал: главный концепт отсутствовал. Теперь готовый концепт с товаром включается даже
   без отметки «Нравится». В альтернативы попадают только понравившиеся варианты.
2. Таблица предметов возле рендера брала первоначальную рекомендацию. Теперь для одного
   выбранного товара берутся его модель и цена выбранной ткани, а не базовая цена другой
   рекомендации. При нескольких выбранных позициях выводится отсылка к списку покупок
   без произвольной единственной цены. Это не означает совпадение товара с изображением.

## Проверка

Синтетические проект, комната, готовые концепты и предмет создаются в отдельной базе
`uyut_qa`. Генерации и реальной покупки нет. Сценарий использует настоящие функции списка,
снимка, сборки данных PDF и HTML-шаблона документа:

- Выбранный зелёный вариант: 79 900 ₽, количество 2, строка 159 800 ₽.
- Подставленные браузером цена 1 копейка и стороннее фото отклоняются в пользу каталога.
- Комната определяется по принадлежащему владельцу предмету; размеры 210 × 90 см
  сохраняются с подписью «размеры введены вами».
- Главный концепт с выбранными товарами побеждает более поздний понравившийся вариант;
  невыбранный и не понравившийся вариант не попадает в альтернативы.
- В HTML есть ссылка выбранной ткани, габариты, отдельная 2D-страница и исключение материалов
  отделки. Общая сумма 527 800 ₽ соответствует двум диванам и работам по 18,4 м².
- При двух вариантах одного предмета нет произвольной цены возле изображения. После
  удаления всех выбранных товаров главным снова становится понравившийся концепт.

11 интеграционных проверок списка, 759 unit-тестов в 87 файлах, типы всех 7 пакетов,
Biome (488 файлов) и production-сборка прошли.
Временная база работала в tmpfs; её контейнер после теста удалён, постоянные тома сохранены.
Изображения в этом сценарии не загружаются; печать Chromium и визуальная проверка страниц
выполнены в предыдущей пачке (`2026-09-27-context-copy.md`), не в этом тесте.

## Что не подтверждено

На production открыты сохранённый концепт кухни и итоги проекта. Список пуст; готового PDF
для скачивания нет. Список пользователя не изменяли и экспорт не запускали: он может
вызвать платный AI-текст. На странице видны старые формулировки; актуальная веб-выкладка
не подтверждена. CI и deploy-jobs для `4779857` успешны, но не доказывают обновление сайта.

API Coolify и SSH отвечают тайм-аутом; владелец подтвердил недоступность панели без VPN
и попросил отложить её восстановление. Проценты roadmap не повышаются от этих тестов.

# Сохранённый интерьер при недоступной очереди

## Найденный дефект

Страница готового концепта владельца без обработки ошибки вызывала
generationStillRunning. Если другая генерация комнаты оставалась активной,
а Trigger не отвечал, ошибка закрывала всю страницу вместе с сохранённым
изображением и товарами. Проверка PDF-повтора аналогичного дефекта не выявила:
неподтверждённая сборка остаётся заблокированной для повторного запуска.

## Изменение

Ошибка проверки очереди оставляет готовый результат доступным. Вместо формы
новой правки показано сообщение о неизвестном статусе и переходе ко всем
вариантам для проверки. Запуск правки через чат также недоступен при неизвестном
или активном запуске. После успешной проверки при следующем открытии страницы
правка доступна снова. Проверки доступа к комнате не входят в обработчик
ошибок очереди и не подавляются.

## Проверка

- 39 профильных unit-тестов прошли: страница концепта, восстановление генерации,
  запуск PDF. Четыре новых контроля: сбой очереди, нормальный повтор открытия,
  активная задача, отказ доступа к комнате.
- Типизация всех 7 пакетов прошла.
- Форматирование и проверка двух изменённых файлов прошли.
- Производственная сборка приложения прошла локально.
- Тесты страницы исполняют серверный компонент с подменённой очередью и
  дочерними компонентами. Это не проверка в настоящем браузере.

Браузерная проверка на локальной production-сборке: 2 E2E passed. Проверены
страница сохранённого концепта при недоступной очереди, отключение/возврат сети,
reload, возврат формы после снятия тестовой брони. Число концептов осталось 2.
Также проверены восстановление PDF по контрольной записи и старая вкладка.
Реальный worker не запускался, отсутствие доступа к очереди задано локальной
конфигурацией, завершение задачи смоделировано только в локальной БД.

Платные запросы не выполнялись. CI и проверка выкладки выполняются после
объединения пакета; результаты выпуска будут записаны отдельно.

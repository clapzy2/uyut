# Интерьер и очередь — локальная техническая приёмка

Дата: 4 октября 2026. Пакет 3 конечного RELEASE_PLAN. Только локально; рабочие
данные сайта и опубликованная история не изменены.

## Что проверено

| Сценарий | Наблюдаемый результат |
| --- | --- |
| Восемь одновременных запросов комнаты | На отдельной БД одну бронь получает один запрос. |
| Поздний ответ старой пачки | Не перезаписывает новый runId и не снимает новую бронь. |
| Потеря ответа после отправки | Бронь остаётся; проверка ищет исходное задание по метке. |
| Пустой поиск или недоступная очередь | Не выдаются за отказ; новая генерация не отправляется. |
| Долгое ожидание без первой картинки | Активная пачка не протухает по возрасту карточек. |
| Конечный отказ worker | Pending-карточки закрываются; ready-карточки и товары сохраняются. |
| Отказ до отправки | Лимитер/однозначный HTTP-отказ освобождают свою бронь. |
| Обновлённый план | UI просит новую сверку окон, дверей и контура; старый результат исключён из актуальных метрик. |
| Старый результат без версии плана | UI отдельно объясняет отсутствие привязки, а не приписывает проверку текущему плану. |
| Подбор не завершился | Изображение доступно; проверка статуса не запускает новую генерацию. |
| Исходник плана не загружен | Пояснение предлагает сверку с исходным планом или фото, а не отсутствующий раздел. |

Задание отправляется с ключом идемпотентности и меткой пачки. Одна попытка SDK
не позволяет последнему HTTP-отказу скрыть неизвестный результат предыдущей
транспортной попытки. Терминальный статус берётся из очереди, не из количества
картинок. Правка, варианты на двоих и общая пачка используют тот же механизм.

## Проверки

- Полный набор web: 187 файлов / 2303 unit-теста; типы семи пакетов,
  lint 712 файлов и production-сборка прошли.
- Девять интеграционных проверок очереди/сверки на отдельной PostgreSQL:
  настоящий механизм БД, ответы SDK замоканы. Это не проверка реального worker.
- Браузер собранного приложения: три состояния сверки, отказ подбора,
  безопасная проверка неизвестной очереди. Узкий и обычный экран.
  Измеренная узкая ширина DOM — 375 px, scrollWidth также 375 px.
- Console ошибок/предупреждений на проверенном маршруте не обнаружено.

Сервер вывел прежнее диагностическое предупреждение Next о
`ResolveMetadata.generateMetadata`; пользовательский сбой не воспроизведён.
Недоступная очередь в контрольном сценарии также записана в серверный лог
ожидаемым сообщением. Это не утверждение о полностью чистых production-логах.

Изображение в браузерном тесте — существующий локальный референс стиля, не
генерация этой квартиры. Это явно указано на странице. Контрольный источник
плана нарисован из сохранённой геометрии, не объявлен физическим обмером.
Временная привязка плана и бронь тестовой спальни после проверки сняты.
Скриншоты сохранены в `output/qa/interior-local-20261004/` вне Git.

## Границы приёмки

Локальная техническая пачка выполнена. Реальная очередь, worker и внешний
подбор принимаются на опубликованном маршруте пакета 5, после разрешения
выкладки. Новый платный benchmark не нужен: прежние 24 изображения разобраны
в `2026-09-27-funded-model-benchmark.md`; сохранение геометрии рендерами и
все ошибки автосверки этим локальным тестом не доказаны.

Если запрос остался неизвестным и очередь не находит задание, автоматического
разрешения на новый запуск нет. Поддержке нужно проверить факт принятия
исходной пачки перед снятием брони; новый production-инструмент снятия брони
этой пачкой не добавлен. Потеря связи сама по себе не доказывает, что деньги
не были потрачены.

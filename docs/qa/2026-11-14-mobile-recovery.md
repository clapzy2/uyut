# Мобильные формы и восстановление после ошибки, 14 ноября

Проверка без физического телефона и без платных запросов.

## Найдено и исправлено

Загрузка аватара не освобождала кнопку при исключении server action. Обрыв
POST воспроизведён локальным E2E до исправления: сообщение отсутствует,
загрузка остаётся незавершённой. Теперь исключение показывает понятную ошибку,
finally освобождает кнопку и input, тот же файл можно выбрать повторно.

Сохранение имени также не объясняло сетевой отказ. Теперь форма сообщает об
ошибке, сохраняет введённый текст и позволяет повторить сохранение.

## Проверено

- Локальный Chromium 320x740, mobile+touch: обрыв сохранения имени, повтор,
  reload; обрыв загрузки аватара, повтор того же файла, reload и чтение из S3.
  Повреждённый JPG отклоняется. Профиль не шире экрана. E2E passed (3.0s).
- Локальный первичный путь 390 px: регистрация, подтверждение письма через
  Mailpit, пять шагов анкеты, референс, повреждённое фото комнаты и успешный
  повтор, reload, доступная генерация, итоговая страница и ошибка PDF без
  очереди. E2E passed (11.0s); генерация не запускалась.
- На действующем сайте: профиль 320 px без переполнения; диалог новой комнаты
  320x568 и 568x320 помещается и прокручивается; смена пароля 320x568 без
  переполнения (пароль не вводился и не менялся). Проект не изменён.
- Biome, typecheck и production build прошли.

Обрывы сети проверялись только локально. Камера, клавиатура ОС, Safari,
реальный телефон и платёж остаются непроверенными. Новый PDF и интерьер не
создавались; живой путь скачивания готового PDF проверен предыдущим пакетом.
Расходы на модели $0. Общую готовность и 60% финальной приёмки не повышаем
за повторную проверку той же платформы.

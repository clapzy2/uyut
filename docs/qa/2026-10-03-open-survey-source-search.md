# Новые открытые исходники обмеров

Дата: 3 октября 2026. Запрос владельца: самостоятельно найти обмер квартиры,
расстановку мебели и исходный CAD. Это отбор документов, не приёмка полного
точного 2D и не новая выкладка. GitHub по просьбе владельца пока не обновлять.

Скачивание доступно без регистрации и оплаты. Оригиналы не изменены и сохранены
локально в `output/pdf/source-search-20261003/`, который исключён из Git.
Публичная доступность не означает разрешение на перепубликацию или обучение
моделей: явную лицензию для такого использования не установили. Не включать
чужие альбомы в публичную демо-базу.

## Проверка текущим читателем PDF

Запущен существующий `preparePlanPage(..., true)` на исходных обмерных листах,
без обращения к платным моделям и без изменения алгоритма под новый документ.

Читаемый PDF или настоящий DWG сам по себе не доказывает правильность геометрии.
CAD в текущий пользовательский маршрут не подключён; скачивание DWG не означает
реализацию такого импорта.

## Итог проверки и следующая пачка

Два первичных разбора и следующая проверка закончены. Режим `aligned` принимает
пять наклонных цепей Ребриной и отвергает подмены соседних подписей, меток и
пропорций. [Производный PDF DWG](2026-10-03-dwg-derived-pdf-control.md) сохранил
37 исходных прямых примитивов и три расчётные размерные связи. Две дуги
видны на листе, но не входят в прямой векторный анализ. Файл не стал
независимым натурным обмером или полноценным импортом CAD.

Следующая пачка — подтверждённая привязка наклонных цепей к контурам/граням
для переноса в редактор. Нативная размерная линия сама по себе не доказывает
владельца стены, точную ширину проёма или замкнутость пола. Не переносить
монтажные изменения назад, не снимать защиты от пропусков и не замыкать
неподтверждённые границы. Новые инструменты скачивать только после согласия
владельца. Доступные локальные проверки не требуют звонков дизайнеру.

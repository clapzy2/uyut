## Защиты продукта

Сервер заново извлекает исходный PDF, проверяет hash, страницу, нативные узлы, размерные
цепочки, принадлежность зон и атомарную ревизию. Старую геометрию перенос не перезаписывает.
Ни помещение, ни размеченный проём не могут молча исчезнуть при преобразовании.

Происхождение масштаба и список проёмов без подтверждённой подписанной ширины сохраняются
сервером, включая последующие ручные изменения. Семь привязок общей зоны остаются такими
неподтверждёнными мерками и блокируют подтверждение. Подмена статуса не делает их пригодными
для точной расстановки или архитектурного задания рендеру. Общая зона не выдаётся за отдельную
комнату по одному номеру. Метрический контур не растягивается независимо по ширине и глубине.

## Проверки

Свежая проверка исходного PDF: 1 206 нативных векторных путей, 192 текстовые подписи.
Все 125 вхождений точек разметки (96 уникальных) найдены точно в свежем источнике.
Все 45 внутренних и 18 внешних рёбер подтверждены исходными линиями либо явно заданным
логическим закрытием проёма. Все 17 подписанных ширин совпадают с исходными подписями.
Логическое закрытие разрыва не означает свободный пол или инженерную модель стены.

В полном метрическом черновике нет ошибок базовой геометрии. Проверка подтверждения
обоснованно оставляет два отказа: неподтверждённые мерки проёмов и несведённые внутренние/
наружные грани физических стен. Не соединяем эти грани выдуманными линиями ради зелёного статуса.

Автоматические проверки покрывают сохранение общей зоны, источника и внешнего контура,
защиту от потери объектов, неправильного масштаба и обхода подтверждения. Локальный SSR-предпросмотр
настоящего компонента проверен на экранах 1440 и 390 px. Это не проверка production или полного
браузерного сценария сохранения. Скриншоты и свежий отчёт находятся в игнорируемом
`output/playwright/complete-metric/`; временные копии PDF удаляются после проверки.

Воспроизведение из `apps/web` (первый аргумент — путь к исходному PDF):

```powershell
bun run scripts/qa-complete-page-probe.ts <source.pdf>
bun run scripts/qa-complete-metric.tsx <source.pdf>
bun run test
```

Из корня: `bun run typecheck`, `bun run lint`, `bun --env-file=.env run build`.
Платных запросов, изменений production и запуска 3D в этой пачке нет.

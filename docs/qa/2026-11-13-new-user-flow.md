# Путь нового пользователя, 13 ноября

## Что проверено

На domitsa.ru открыт прежний QA-аккаунт с пятью проектами. Бесплатный лимит
исчерпан, регистрация переадресует авторизованного пользователя в проекты.
Новый аккаунт на рабочем сайте не создавался; старые проекты не менялись.
Полный живой путь нового пользователя до генерации и PDF **не подтверждён**.

Самостоятельно запущен локальный Docker и отдельный экземпляр Домицы на 4300.
Другой проект на порту 3000 и другие контейнеры не останавливались. Все новые
аккаунты и письма браузерных тестов относятся к localhost и Mailpit.
Платные запросы не запускались, расход **$0**.

## Исправлено одним пакетом

1. Возврат со второго шага показывает сохранённые название и комнаты, позволяет
   изменить их существующими формами и добавить комнату. Второй проект не создаётся.
2. Пока файл референса загружается, нельзя завершить анкету, пропустить шаг или
   уйти назад. После результата загрузки управление снова доступно.
3. Проект и комнаты создаются в одной транзакции. При ошибке вставки комнаты
   пустой проект не остаётся занимать бесплатный лимит. Замена оценок стиля и
   обновление вектора также атомарны: ошибка сохраняет прежние ответы.
4. Ссылки референсов скачиваются с проверкой адреса непосредственно при DNS lookup
   соединения, каждого редиректа и og:image. Приватные адреса запрещены, тела
   ограничены в потоке (10 MiB картинка, 200 KB HTML), общий таймаут 8 секунд.
   Права владельца проверяются до скачивания/записи. AAAA-only домены пока не
   поддержаны; файл можно загрузить напрямую.
5. Регистрация требует consent=true на сервере. Отсутствующий/false запрос
   отклоняется без создания аккаунта; сервер не фиксирует вымышленное согласие
   для иных способов создания пользователя. Обычная форма передаёт значение.

## Готовность

Проценты не повышаем: исправлены конкретные ошибки первого входа, но новый
пользователь на production ещё не прошёл всю цепочку. Следующая приёмка требует
отдельного рабочего аккаунта без проектов: фото -> одна серия -> товар -> PDF.
Оплату и новое создание пароля человек завершает самостоятельно в браузере.

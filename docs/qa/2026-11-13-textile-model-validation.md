## Проверка сохранённых кадров и найденные ошибки

Через текущую модель выполнены сравнения двух старых кадров с исходником:

- 613f03d6-e826-41cb-a74a-a94649170bd7: ложной претензии к цвету подушек нет,
  но возникло ложное замечание о конструкции пледа. Наблюдатель описал один плед
  на исходнике и комбинацию пледа с перекрашенным покрывалом на результате.
- 88b9b2d2-4309-4782-881f-7bc458c72803: модель правильно заметила, что основное
  покрывало осталось светлым вместо терракотового. Ложной претензии к подушкам нет.

Исправление: наблюдатель конструкции должен указать appearanceScope=target_only;
соседние предметы и нижний слой не являются конструкцией самого пледа. Ответы без
границы проверки, adjacent_objects и uncertain остаются limited без предупреждения.
Обычные изменения конструкции и числа частей продолжают проверяться.

Повторён только первый сохранённый кадр, без нового рендера: модель самостоятельно
описала неизменившийся тёмный плед поверх перекрашенного покрывала, returned
unchanged / target_only; итог checked, issues=[], sourceComparison=verified.
Это один успешный повтор с новыми инструкциями, не гарантия стабильности всех ответов.
Локальные результаты, ответы модели, request ID и хеши: tmp/textile-model-check/.

На сайте выявлена вторая ошибка: «основного белого покрывала, покрывающего всю
кровать» ошибочно требовало уточнения. Разбор теперь допускает промежуточные
прилагательные и причастное уточнение. Точная фраза покрыта регрессией.
Для запуска серии использована понятная старой версии формулировка «основного
покрывала белого цвета». При нуле шагов UI больше не обещает три будущих варианта.
